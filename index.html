Tentang

Sebuah Perjalanan

Titik Awal

Latar belakang saya bukan dari dunia teknologi. Saya seorang teknisi WiFi lapangan, lulusan SMK Teknik Kendaraan Ringan — dan sedang membangun jalan baru menuju Frontend Development.

Cara Saya Belajar

Dari rasa ingin tahu itu, saya menemukan pemrograman: cara membangun sesuatu yang memberi ruang tepat untuk terus menguji cara berpikir saya. Saya belajar secara otodidak dari fondasi — HTML, CSS, responsive design, accessibility, hingga JavaScript — dengan AI sebagai pendamping untuk riset, memahami konsep, dan code review. Keputusan dan proses berpikir tetap menjadi milik saya sendiri.

Titik Temu

Frontend, bagi saya, adalah titik temu antara logika di balik sebuah sistem dan cara manusia berinteraksi dengannya.

Bukan Sekedar Hasil

Portfolio ini adalah dokumentasi perjalanan itu — bukan sekadar kumpulan hasil akhir, tapi catatan tentang bagaimana saya belajar, membangun, menemukan masalah, dan berkembang.
